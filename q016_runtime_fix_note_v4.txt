Q016 V4 TECHNICAL REPAIR

V3 observed failure:
REFERENCE_GATE=FAIL reference is not pointlike

ROOT CAUSE
The gate was logically wrong for Cobaya. In Cobaya 3.5.6,
reference_is_pointlike is true only when every sampled parameter has a fixed
numeric reference. Q016 intentionally uses Gaussian reference distributions
for multistart profiling, so False is expected and valid.

V4 REPAIR
- Removes pointlike=True as a requirement.
- Uses Prior.reference() to draw the technical start reference.
- Uses a deterministic branch/restart-specific RandomState seed.
- Requires correct vector dimension, finite values, and finite logposterior.
- Records reference_is_pointlike as diagnostics only.

SCIENTIFIC EFFECT
NONE. Likelihoods, priors, bounds, n=3 EDE, H0=71.5, TT/TE/EE,
ell=600-2000, tau treatment, covariance rules, no-cross-chain rules and
scientific pass/fail gates are unchanged.
